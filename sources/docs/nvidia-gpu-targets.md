# NVIDIA GPU compute capability mappings

The official product table identifies Jetson Orin as CC 8.7, GeForce RTX 4090 as
8.9, H100/H200 as 9.0, B200/GB200 as 10.0, B300/GB300 as 10.3, and Jetson
T5000/T4000 (Thor) as 11.0. RTX 50-series devices are listed under 12.0.
Product names and base compute capability do not establish compiler suffixes,
per-SKU resources or feature-specific library support.
